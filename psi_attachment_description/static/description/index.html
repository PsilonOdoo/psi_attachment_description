Attachment Description

Adds descriptions to attachments in Odoo

Supported Editions:
Community
Enterprise
Odoo.sh

SHORT OVERVIEW

The module allows you to add descriptions for attachments across any Odoo model that supports chatter. Descriptions can be added in forms on the website or in the backend using chatter. Descriptions can be added for each attachment type.

SCREENSHOTS

Website Form

Extend your Website Form by adding descriptions to attachments.

The extended template allows you to add descriptions to both documents and images. The form supports multiple attachments. After adding a file, click the comments icon (fa-comments) to open an input field where you can enter a description

Add/Edit description

Bring clarity to every attachment

A new comment icon is added to each attachment in the chatter. Click the comment icon to open a dialog where you can add or update the description.

Update Description

Save your changes effortlessly

Quickly update the description of any attachment. Open the dialog, edit the text, and save — all changes are applied instantly.

View Description

See attachment details at a glance

After saving in the dialog, the description is stored and displayed directly in the chatter for easy reference.

Description image

Images can now also have their own descriptions

A new "Description" action appears in the menu. Clicking it opens a dialog where you can add or edit the description. The description is stored exclusively in this dialog, keeping the chatter clean.
